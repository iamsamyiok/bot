# 隐私边界

- **本地数据**: 记忆(ReMe)、任务账本(ledger)、配置(bot.json)、上传文件 —— 全部在你电脑, 仓库不含任何运行时数据
- **密钥**: 只存本机 config/bot.json(已 gitignore), 也可走环境变量
- **LLM 提供商**: 你配置的 base_url 指向谁, 你的对话就发给谁。**涉密任务**两个选择: 配本地 Ollama 端点, 或让消息包含涉密关键词自动走 codex 私有引擎(其内容由你自己的 codex 账号策略管辖)
- **审批闸**: 高危动作在执行前停下等你拍板, 这是尽力防护而非安全边界 —— 最终责任在操作者
- **遥测**: 无。不收集任何数据。
